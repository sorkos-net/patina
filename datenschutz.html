Datenschutz

Browser-Erweiterung

Patina übermittelt keine personenbezogenen Daten an uns oder an Dritte. Die Erweiterung enthält keine Analyse-, Telemetrie- oder Werbedienste und stellt keine Netzwerkverbindungen zu einem eigenen Backend her.

Patina verarbeitet lokal die gewählten Einstellungen, Zeitstempel für geöffnete und zuletzt angesehene Tabs sowie den ursprünglichen und den von Patina ergänzten Seitentitel. Diese Angaben werden ausschließlich im vom Browser verwalteten lokalen oder sitzungsbezogenen Speicher abgelegt. Patina liest nur den Seitentitel. Übrige Seiteninhalte und Website-Adressen werden weder als Tab-Identität verwendet noch von Patina gespeichert.

Die optional aktivierbare Aufräumfunktion schließt inaktive Tabs nach dem selbst festgelegten Zeitraum. Auch dabei werden keine Tab-Daten übertragen.

Sitzungsbezogene Tab-Daten werden entfernt, wenn der zugehörige Tab geschlossen oder der Browser-Speicher gelöscht wird. Einstellungen bleiben gespeichert, bis sie geändert, der Browser-Speicher gelöscht oder die Erweiterung deinstalliert wird. Eine Weitergabe dieser Daten findet nicht statt.

Diese Website

Diese Website wird als statische Seite über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet GitHub technisch erforderliche Verbindungsdaten, insbesondere die IP-Adresse sowie Angaben zum angeforderten Inhalt, Browser und Zeitpunkt des Zugriffs. Auf dieser Website setzen wir keine eigenen Cookies, Analysewerkzeuge, externen Schriftarten oder Formulare ein.

Weitere Informationen zur Verarbeitung durch GitHub enthält die Datenschutzerklärung von GitHub .
