Privacy

Browser extension

Patina does not transmit personal data to us or to third parties. The extension contains no analytics, telemetry, or advertising services and makes no network requests to a backend of its own.

Patina processes your settings, timestamps for opened and last-viewed tabs, and the original and modified page titles locally. This data is stored only in local or session storage managed by your browser. Patina reads only the page title. It does not use or store other page content or website addresses.

The optional cleanup feature closes inactive tabs after a period you choose. No tab data is transmitted when this feature is used.

Session-related tab data is removed when the corresponding tab is closed or browser storage is cleared. Settings remain until you change them, clear browser storage, or uninstall the extension. This data is not shared with anyone.

This website

This static website is hosted on GitHub Pages. When you visit it, GitHub processes connection data required to provide the site. This may include your IP address, the requested content, your browser, and the time of access. We do not use our own cookies, analytics tools, external fonts, or forms on this website.

For more information about how GitHub processes data, see the GitHub Privacy Statement .

Contact

You can ask technical questions about Patina in the public issue tracker. Do not post confidential or personal information there.
